## 站点访问控制机制（实测）

这是本次采集最关键的结论，记录下来便于后续复用。

1. **未登录**：每个认证仅公开前 10 题。请求第 2 页会被 302 跳转到注册页。
2. **免费账号**：每科另有 20–30 题的免费预览额度。站点原文：
   `After Questions 21-30, Contributor Access or PRO will be required to continue.`
3. **检查点机制**：免费额度内第 2 页起，同一 URL 连续请求会在「检查点提示页」与
   「题目内容页」之间**交替**，需重试命中。首次请求返回检查点，二次请求才给内容。
4. **URL 形式**：第 1 页的规范 URL 是 `{base}/view/`，用 `/view/1/` 会 302。
5. **Referer**：必须带该考试的题目首页 `{base}/view/`，否则可能拿到检查点页。
6. **付费墙**：超出免费预览后为 Contributor Access（单科 1 或 3 个月）或
   PRO（10 科 3 个月）。**本次采集在付费墙处主动停止，未触碰任何付费内容。**
7. **会话漂移**：免费预览额度是账号级、不可逆的。请求顺序不当（如跳过第 2 页直接
   请求第 3 页）会让指针前移，导致该页内容此后完全无法再取回。**抓取必须严格按
   页序推进，每页重试到命中内容再进入下一页。**
8. **CF 绑定**：`cf_clearance` 与 UA / IP 绑定，抓取必须使用与浏览器一致的
   Chrome 158 macOS UA。

> **付费方案说明**：ExamTopics 的 Contributor / PRO 属于付费内容，本次未购买。
> 题量扩充改由两条不需付费的路径完成：① 站外免费题库（examstrack、solution2pass 等）；
> ② GitHub 开源备考仓库（学习笔记 + 自编题 + 交互测验）。

## 中文翻译

题库保留 **英文原文 + 中文对照** 双语形式：实际考试语言为英文，中文仅作理解辅助。

- **覆盖范围**：1224/1224 题干、4933/4933 选项、1224/1224 正确答案、711 道题的中文解析。
- **学习指南**：570 篇中，267 篇为中文原文直接收录，233 篇英文指南已生成中译
  （中文可读覆盖率 88%），70 篇代码密集的实操手册仅提供原文链接。
- **长文分块翻译**：原先英文指南超过 3.6 万字符即整篇跳过，最长的
  `GSA/.../Study_Plan.md`（原始 32 万字符）被完全排除。现改为**围栏感知**切块：
  在代码块之外的 Markdown 标题边界处切成 ≤2.2 万字符的块，逐块翻译后按块序拼接回整篇；
  切分结果用「源文本归一化后完全一致」与上一轮译文对齐，复用 31 块、仅重译 9 块。
  全文提取上限由 4 万字符提高到 12 万字符，仅 `Study_Plan.md` 仍超限并附截断提示。
- **术语规范**：技术术语（GPU、NVLink、InfiniBand、CUDA、MCP、RAG 等）保留英文原文；
  命令、配置项、参数名、产品名一律不译；统一译法表见 `raw/translate/TASK_PROMPT.md`。
- **实现方式**：环境无外部翻译 API，改由子代理并行翻译——共享指令文件，
  题目每批 20 题落盘为 `raw/translate/out/batch_<编号>.json`，
  指南每批约 2.2 万字符落盘为 `raw/translate/guides/out/g<编号>.json`，
  再由合并脚本按 id 合并回数据集（分块译文按 `<gid>#cN` 汇总为整篇）。
- **译文一致性校验**：翻译批次是以「某一版数据集快照」的题目编号生成的，数据集重建后
  编号会平移，导致译文整体错位。已改用「按英文原文内容重新配对」的方式修正（见
  `tools/fix_translation_alignment.py`）。

## 已知问题与修正

- **译文编号错位（本次最重要的一次修正）**：翻译批次按旧数据集快照的编号生成，
  数据集重建后题目编号平移，导致 69 道题的中文译文被套用到别的题目上（表现为
  「中文选项与英文题干完全对不上」，而非单纯缺选项）。根因是合并脚本按
  `slug#题号` 匹配，而题号本身已变。修复方式为按**英文原文内容**重新配对
  （`tools/fix_translation_alignment.py`），配对后仍有 61 题缺译或选项不全，
  单独重译补齐。
- **子代理漏选项**：含 A–F 六个选项的题目，翻译输出偶发只给 A–D。已在批次指令中
  明确要求逐项核对字母序列，并在合并后做「选项字母集合 == 输入选项字母集合」的校验。
- **指南去重误删**：早期按正文前 600 字符做哈希去重，把同模板的不同章节误判为重复
  （OUSD 9 篇笔记只剩 1 篇）。已改为全文哈希。
- **代码块阈值误伤**：早期「代码块数 > 40 即丢弃」的规则误删了 OpenUSD 学习笔记
  （USD 代码片段正是其核心内容）。已放宽至 120。
- **跨厂商指南误分类**：多厂商混合库中 Salesforce / Cisco / AWS 指南因正文提及
