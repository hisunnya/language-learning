# 词境 · 家庭版 / 班级版 部署说明

带登录的版本：学生用**学号**登录，成绩按人记录，你（管理员）导入名单、重置密码、按班级导出成绩。
局域网版（`deploy/install.sh`）完全不变，两个版本可以装在同一台机器上，也可以分开装。

```
学生手机 --HTTPS--> Tailscale Funnel --HTTP--> nginx 127.0.0.1:8081 --> 后端 127.0.0.1:8766
```

后端和 nginx 都只监听本机，**对外的唯一入口是 Funnel**。

---

## 一、先看这几条（上线前必须过一遍）

1. **不要装在 PVE 宿主机上。** 在 PVE 里新建一个 LXC 容器或虚拟机（Debian 13 即可），
   只在里面装本程序和 Tailscale。宿主机上有 PVE 管理界面和 SSH，不要跟公网沾边。
   **完整步骤（建容器、放行 TUN、装 Tailscale、关密钥过期、备份）见 [`PVE容器部署.md`](PVE容器部署.md)。**
2. **主机名别叫 `pve03`。** Funnel 的网址里带着机器名，起个中性的，例如 `lexica`：
   `sudo tailscale set --hostname=lexica`。
3. **tailnet 名字在发出网址之前定下来。** 管理后台 → DNS → Rename tailnet，只能从随机生成的里挑；
   以后再改，所有发出去的链接和二维码都会失效。
4. **这个网址是公开的。** 开 Funnel 后几分钟内就会有扫描器来探 `/.env`、`/AGENTS.md`、`/config.js` 之类
   （我们测试时实测过）。所以：登录必须开着、nginx 的拦截规则必须在、不要用 `python3 -m http.server` 之类临时服务
   对外开放（它会把当前目录下的所有文件都暴露出去）。
5. 容器里用到的是 Funnel 的 443 端口，**家里路由器不用做任何端口映射**（家宽在运营商级 NAT 后面，映射也没用）。

## 二、安装

在容器里，拿到完整的仓库（`git pull`），然后：

```bash
sudo env WP_PUBLIC_URL=https://lexica.tailXXXX.ts.net bash word-puzzle/deploy/family/install.sh
```

`WP_PUBLIC_URL` 是你之后会用的对外地址（还没开 Funnel 也要先定好，格式 `https://主机名`，不带斜杠）。
脚本会装好服务和 nginx，并做自检：未登录访问接口必须返回 401，不通过就报错退出。
它**不会**碰 Tailscale 和 Funnel。

可选环境变量：`WP_FAMILY_PORT`（后端，默认 8766）、`WP_FAMILY_NGINX_PORT`（默认 8081）、
`WP_FAMILY_INSTALL_DIR`、`WP_FAMILY_DATA_DIR`。

## 三、创建管理员、导入名单

```bash
sudo wp-family-admin create-admin 你的工号 --name 你的名字      # 会提示输入密码（不要写在命令里）
sudo wp-family-admin import /tmp/名单.xlsx --out /tmp/初始密码.csv
```

名单是 Excel（.xlsx）或 CSV（UTF-8 或 GBK 都行）。必须有「学号」「姓名」两列，
可选「班级」「学院」「院系」「初始密码」「标签」（见下一节）。**手机号、用户名等其他列不会被保存**（导入时会提示）。

- 每个学生得到一个随机的 8 位初始密码，写进你指定的 `初始密码.csv`（权限 600，明文，**发完请删除**）。
- 学生第一次登录必须先改成自己的密码；新密码至少 8 位、字母数字符号至少两种、不能含学号。
- 重复导入同一份名单不会重复建号，也不会动已有密码；加 `--reset-existing` 才会给已有学号重新发密码。
- 也可以登录后在网页的「账号管理」里上传名单、重置密码、停用账号、解锁、导出成绩。

其他命令：`reset-password 学号`、`unlock 学号`、`disable 学号`、`enable 学号`、`list [--class-name 班级]`。

规则：连续输错 5 次密码会锁定该账号 15 分钟（管理员可以提前解锁）；会话 14 天有效；
改密码或被重置后，该账号在其他设备上的登录全部失效。

## 三（续）、标签和分类：学生能看到哪些题库

家庭版里，**学生只能看到、打开和自己至少有一个相同标签的题库**；题库管理只有老师账号能用。

| | 学生 | 老师 |
|---|---|---|
| 看到的题库 | 只有和自己标签相同的 | 全部（包括没打标签的） |
| 玩、记成绩 | 只能在自己看得到的题库上 | 随便 |
| 建题库、删题库、上传资料、生成离线页、改标签 | 不能（页面上也看不到入口，服务端同样拒绝） | 能 |
| 首页 | 只有「选个题库」列表，按分类分组 | 还有生成题库、离线页、默认题库等 |

- **标签**决定权限；**分类**只用来整理（例如「教材同步」「考试词汇」），不影响谁能看到。
- 标签用逗号隔开，每个最多 20 个字、一个人或一个题库最多 10 个。
- **没打标签的题库，学生看不到**。内置教材题库也一样，所以上线后要先给题库打标签。
- 局域网版（没有登录）不受影响，题库照旧全部可见。

怎么设置：

1. 给学生打标签：导入名单时加一列「标签」（有内容就整组替换，空着或没有这一列则保持原样）；
   或者在「账号管理」里点某个学生的「标签」按钮；也可以先用班级等筛选，再用上面的
   「批量改标签」一次给列表里所有学生加上或去掉标签。
2. 给题库打标签和分类：登录老师账号，在首页题库列表里点「分类和标签」。
3. 学生重新打开首页就能看到变化，不需要重新登录。

**第一次启用时的步骤**（现有题库都还没有标签，学生会暂时什么都看不到）：
先给学生打好标签，再给要开放的题库打上相同的标签，最后用一个学生账号登录确认看得到。
内置教材题库在词库更新后会被自动重建，分类和标签会一起保留。

## 四、开 Funnel（确认过再开）

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up                         # 浏览器里登录授权
sudo tailscale set --hostname=lexica
tailscale funnel --bg 8081                # 具体参数以 tailscale funnel --help 为准
tailscale funnel status
```

开之前对照检查清单：

- [ ] 容器里没有别的网页服务在监听（`ss -ltnp`），Funnel 只指向 8081
- [ ] `curl http://127.0.0.1:8081/word-puzzle/api/banks` 返回 401
- [ ] `curl -I http://127.0.0.1:8081/.env` 返回 404
- [ ] 管理员账号已经创建，并能登录、能看到「账号管理」
- [ ] 用**没装 Tailscale 的手机、关掉 Wi-Fi** 打开对外网址能看到登录页
      （装了同一个账号的设备解析到的是内网地址，没经过 Funnel，测不准）

关掉：`sudo tailscale funnel reset`。

## 五、日常维护

- 备份：数据库就是 `/var/lib/word-puzzle-family/app.db` 一个文件。定期用
  `sqlite3 app.db ".backup '/备份目录/app-日期.db'"` 备份到另一块盘，或者让 PVE 对这个容器做定时备份。
  备份文件里有学号、姓名和密码哈希，同样要保管好。
- 日志：`journalctl -u word-puzzle-family`，nginx 的在 `/var/log/nginx/word-puzzle-family.*.log`。
  Funnel 后面看到的客户端地址都是 127.0.0.1，查不出真实来源；登录失败看后端日志里的 401。
- 更新：`git pull` 后重新运行第二步的安装命令即可，数据库不会被覆盖。
- 学生的数据：只存学号、姓名、班级、学院、院系和成绩。不存手机号。毕业或不用时，在管理页停用账号；
  要删除数据直接联系我或用 sqlite 删对应行。

## 六、已知的限制

- Funnel 带宽有上限且不能调；本站流量小，一个班同时上课一般够用，如果卡顿再评估。
- Funnel 在国内的可达性取决于 Tailscale 的线路，实测可用，但无法保证长期稳定。
  万一不通，备选是带固定 IP 的 VPS + frp（要花钱），或者改用微信小程序版。
- 登录限流是「单账号锁定 + 全站总量」，没有按来源 IP 限流（Funnel 后面看不到真实 IP）。
