# 语林 Lingua Grove · 部署说明

总主页是**纯静态**的，没有任何后端依赖，拷贝过去就能用。
默认 nginx 拓扑是 hub 和四个项目共用 80 端口：词境 `/word-puzzle/`、每日话题 `/topics/`、无线电执照 `/ham/`、化学探秘 `/chemistry/`。

---

## 一、文件结构

```
hub/                       ← 整个目录放到服务器
├── index.html             主页面
├── css/hub.css            五套配色
├── js/hub.js              中英切换 + 配色切换
├── js/config.js           三个子站的地址（部署时改这里）
├── deploy/install.sh      部署三件工具并切换 nginx 总入口
├── deploy/lingua-grove.conf   nginx 站点配置模板
└── tests/test_hub.py      样式规范测试
```

---

## 二、一键部署与整体测试

确认词境后端已部署并运行，然后在仓库目录执行：

```bash
sudo env LINGUA_SERVER_NAME=10.211.55.5 bash hub/deploy/install.sh
```

脚本会检查依赖（已装的跳过）、部署 hub/话题/Ham Exam/化学探秘四个静态目录，
把统一 nginx 配置写入 `/etc/nginx/conf.d/lingua-grove.conf`，并停用旧版
`sites-enabled` 中的 hub / 词境站点链接。
词境的 systemd 服务和后端不变，nginx 在 `/word-puzzle/` 提供页面并将 `/word-puzzle/api/` 转发给后端。

部署后做整站冒烟测试：
```bash
curl --noproxy '*' -fsS http://10.211.55.5/ | grep -q 'Lingua Grove'
curl --noproxy '*' -fsS http://10.211.55.5/topics/ | grep -qi '<html'
curl --noproxy '*' -fsS http://10.211.55.5/ham/ | grep -qi '<html'
curl --noproxy '*' -fsS http://10.211.55.5/chemistry/ | grep -qi '<html'
curl --noproxy '*' -fsS http://10.211.55.5/word-puzzle/api/health
```

### 3. 确认三个子站在哪儿

`hub/js/config.js` 里写着三个子站的地址。默认都使用同域路径：

```js
window.LINGUA_PROJECTS = {
  lexica: "/word-puzzle/",
  topics: "/topics/",
  ham:    "/ham/",
  chemistry: "/chemistry/",
};
```

| 部署方式 | 改法 |
| --- | --- |
| 同一台服务器（默认） | hub 和三个项目都在 80；保持默认配置 |
| 词境使用不同主机或端口 | 把 `lexica` 改成对应的完整地址 |
| 不同域名 | 改成 `http://lexica.lan/` 这种完整地址 |

改完刷新页面即可，不用动 HTML。

## 三、四个子站各自的部署

| 子站 | 位置 | 怎么装 |
| --- | --- | --- |
| 词境 Lexica | `/srv/word-puzzle` | 后端由 `word-puzzle/deploy/install.sh` 安装；本部署脚本挂载在 `/word-puzzle/` |
| 每日话题 | `/var/www/topic-app` | 见 `topic-app/部署说明.md` |
| 无线电执照 | `/var/www/ham-exam` | 纯静态，把 `ham-exam/` 拷进去即可 |
| 化学探秘 | `/var/www/chemistry` | 纯静态，把 `chemistry/` 拷进去即可 |

若词境改用其他主机或端口，把 `config.js` 中的 `lexica` 改成对应完整地址。
