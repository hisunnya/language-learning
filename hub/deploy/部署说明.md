# 语林 Lingua Grove · 部署说明

总主页是**纯静态**的，没有任何后端依赖，拷贝过去就能用。
默认 nginx 拓扑是 hub、每日话题和无线电执照共用 80 端口，词境 Lexica 单独使用 8082。
词境页面使用根路径的静态资源和 API，不能直接挂在 `/lexica/` 子路径。

---


## 二、一键部署与整体测试

确认词境后端已部署并运行，然后在仓库目录执行：

```bash
sudo env LINGUA_SERVER_NAME=10.211.55.5 bash hub/deploy/install.sh
```

脚本会检查依赖（已装的跳过）、部署 hub/话题/Ham Exam 三个静态目录、
启用 hub nginx 站点，并停用词境原来单独占用 80 端口的站点链接。
词境的 systemd 服务和后端不变，nginx 在 8082 提供它的页面和 API。

部署后做整站冒烟测试：
```bash
curl --noproxy '*' -fsS http://10.211.55.5/ | grep -q 'Lingua Grove'
curl --noproxy '*' -fsS http://10.211.55.5/topics/ | grep -qi '<html'
curl --noproxy '*' -fsS http://10.211.55.5/ham/ | grep -qi '<html'
curl --noproxy '*' -fsS http://10.211.55.5:8082/api/health
```

### 3. 确认三个子站在哪儿

`hub/js/config.js` 里写着三个子站的地址。默认配置让词境使用当前主机的 8082 端口，
话题和 Ham Exam 使用同域路径：

```js
window.LINGUA_PROJECTS = {
  lexica: window.location.protocol + "//" + window.location.hostname + ":8082/",
  topics: "/topics/",
  ham:    "/ham/",
};
```

| 部署方式 | 改法 |
| --- | --- |
| 同一台服务器（默认） | hub 在 80，词境在 8082；保持默认配置 |
| 词境使用不同端口 | 把 `lexica` 改成对应端口的完整地址 |
| 不同域名 | 改成 `http://lexica.lan/` 这种完整地址 |

改完刷新页面即可，不用动 HTML。

---

## 三、三个子站各自的部署

| 子站 | 位置 | 怎么装 |
| --- | --- | --- |
| 词境 Lexica | `/srv/word-puzzle` | 后端由 `word-puzzle/deploy/install.sh` 安装；本部署脚本统一由 8082 提供词境页面和 API |
| 每日话题 | `/var/www/topic-app` | 见 `topic-app/部署说明.md` |
| 无线电执照 | `/var/www/ham-exam` | 纯静态，把 `ham-exam/` 拷进去即可 |

总主页占用 80 端口，词境入口走 8082。若服务器启用了 UFW，还需允许 8082/tcp：

```bash
sudo ufw allow 8082/tcp
```

若词境改用其他主机或端口，把 `config.js` 中的 `lexica` 改成对应完整地址。
