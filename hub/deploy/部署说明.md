# 语林 Lingua Grove · 部署说明

总主页是**纯静态**的，没有任何后端依赖，拷贝过去就能用。
默认 nginx 拓扑是 hub、每日话题和无线电执照共用 80 端口，词境 Lexica 单独使用 8082。
词境页面使用根路径的静态资源和 API，不能直接挂在 `/lexica/` 子路径。

---

## 一、文件结构

```
hub/                       ← 整个目录放到服务器
├── index.html             主页面
├── css/hub.css            五套配色
├── js/hub.js              中英切换 + 配色切换
├── js/config.js           三个子站的地址（部署时改这里）
├── deploy/lingua-grove.conf   nginx 站点配置
└── tests/test_hub.py      样式规范测试
```

---

## 二、部署步骤

### 1. 拷贝文件

```bash
# 在开发机上
scp -r hub/index.html hub/css hub/js  user@10.1.1.93:/tmp/

# 在服务器上
sudo mkdir -p /var/www/lingua-grove
sudo cp -r /tmp/{index.html,css,js} /var/www/lingua-grove/
sudo chown -R www-data:www-data /var/www/lingua-grove
```

### 2. 装 nginx 站点

```bash
sudo cp /path/to/lingua-grove.conf /etc/nginx/sites-available/lingua-grove
sudo ln -s /etc/nginx/sites-available/lingua-grove \
         /etc/nginx/sites-enabled/lingua-grove
sudo nginx -t && sudo systemctl reload nginx
```

### 3. 确认三个子站在哪儿

`hub/js/config.js` 里写着三个子站的地址。默认配置让词境使用当前主机的 8082 端口，
话题和 Ham Exam 使用同域路径：

```js
window.LINGUA_PROJECTS = {
  lexica: window.location.protocol + "//" + window.location.hostname + ":8082/",
  topics: "/topics/",
  ham:    "/ham/",
};
```

| 部署方式 | 改法 |
| --- | --- |
| 同一台服务器（默认） | hub 在 80，词境在 8082；保持默认配置 |
| 词境使用不同端口 | 把 `lexica` 改成对应端口的完整地址 |
| 不同域名 | 改成 `http://lexica.lan/` 这种完整地址 |

改完刷新页面即可，不用动 HTML。

---

## 三、三个子站各自的部署

| 子站 | 位置 | 怎么装 |
| --- | --- | --- |
| 词境 Lexica | `/srv/word-puzzle` | `sudo word-puzzle/deploy/install.sh` 安装 systemd 和原站点；本配置另在 8082 提供同一套页面 |
| 每日话题 | `/var/www/topic-app` | 见 `topic-app/部署说明.md` |
| 无线电执照 | `/var/www/ham-exam` | 纯静态，把 `ham-exam/` 拷进去即可 |

安装词境时，安装脚本还会创建原有的 80 端口站点；可继续通过原域名访问。
总主页的词境入口走 8082。若服务器启用了 UFW，还需允许 8082/tcp：

```bash
sudo ufw allow 8082/tcp
```

若词境改用其他主机或端口，把 `config.js` 中的 `lexica` 改成对应完整地址。

## 四、验证

```bash
# 页面能打开
curl -sI http://10.1.1.93/ | head -1

# 三个入口的地址对得上
curl -s http://10.1.1.93/ | grep -o 'data-project-link="[a-z]*"'

# 词境页面和接口通
curl -sI http://10.1.1.93:8082/ | head -1
curl -s http://10.1.1.93:8082/api/health
```

浏览器里再点一遍：切语言、切配色、三个入口分别点开。
