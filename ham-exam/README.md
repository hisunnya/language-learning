# 业余无线电台操作技术能力验证 · 模拟考试系统

一个**纯本地**的刷题网站：自己电脑上打开就能用，不需要装任何东西，不联网、不登录、不需要数据库。

题库来自《业余无线电台操作技术能力验证题库（2025 年版）》，题量与官方完全一致：

| 类别 | 题量 | 其中单选 | 其中多选 | 附图题 | 知识点 |
|---|---:|---:|---:|---:|---:|
| A 类 | 683 | 547 | 136 | 1 | 51 |
| B 类 | 1143 | 947 | 196 | 24 | 95 |
| C 类 | 1282 | 1072 | 210 | 53 | 104 |

合并去重后共 **1375** 道题、**112** 个知识点（三个类别的题目有重叠，级别越高包含越多）。

## 一、怎么打开

### 方式 1：直接双击（最简单）
双击 `index.html`，用 Chrome / Edge / Firefox 打开即可。全部功能可用。

> 题库数据以 `data/bank.js` 的形式内嵌，附图是普通图片文件，所以走 `file://` 协议也不会被浏览器拦截。

### 方式 2：起个本地服务（推荐，行为更接近正常网站）
```bash
cd ham-exam
python3 -m http.server 8080
# 然后浏览器打开 http://127.0.0.1:8080
```
或者用 macOS / Linux 自带的：
```bash
./start.sh
```

## 二、四个模块

### 1. 模拟考试
规则与正式考试**完全一致**：

| 类别 | 试卷 | 时长 | 合格线 |
|---|---|---:|---:|
| A 类 | 40 题（单选 32 + 多选 8） | 40 分钟 | 答对 30 题 |
| B 类 | 60 题（单选 45 + 多选 15） | 60 分钟 | 答对 45 题 |
| C 类 | 90 题（单选 70 + 多选 20） | 90 分钟 | 答对 70 题 |

- 随机抽题，题序打乱
- 倒计时结束**自动交卷**，最后 5 分钟变黄、最后 1 分钟变红闪烁
- 答题卡：已答 / 未答 / 已标记一目了然，点击跳题
- 未作答按错计
- **多选题必须与标准答案完全一致才得分**，少选、多选、错选一律不得分（和正式考试一样）
- 考试中途刷新页面不会丢——作答进度实时存在本地，关掉页面重开还能「继续上次未完成的考试」
- 交卷后给出：得分、正确率、用时、是否合格、**本卷知识点表现**（正确率低的排在前面）、逐题回顾（标绿正确 / 标红你选的）

### 2. 练习模式
- 随机抽题、**不限时**，答完立刻显示对错 + 正确答案 + 知识点
- 题量可选 10 / 20 / 30 / 50 / 不限
- 范围可选：全部、仅单选、仅多选、仅附图、**仅错题**、仅未做过的、仅收藏
- 也可以限定某个知识点
- 随时「结束练习」，给出小结

### 3. 题库（遍历）
- 左侧是**知识点目录树**（5 大部分 / 29 个二级 / 112 个三级），数字是当前类别下的题量，没有题目的会置灰标 ✕
- 右侧逐题浏览，可展开看答案；「全部展开 / 全部收起」
- 顶部支持全文搜索（题干、选项、编号）
- 筛选：全部 / 单选 / 多选 / 附图 / 未做过 / 做错过 / 收藏
- 每题可点星收藏
- 「就这些题练一轮」——把当前筛选结果直接拉进练习模式

### 4. 统计
- **总览**：题库总量、已做题数、覆盖率、总正确率、错题数、模拟考试次数、平均得分
- **知识点掌握度**：112 个知识点逐个列出题数 / 已做 / 正确率条，**正确率低的排在最前面**，一键「练这节」针对薄弱项专项突破
- **模拟考试记录**：每次考试的时间、类别、得分、正确率、用时、是否合格，可「错题重练」
- **错题本**：自动收录做错的题，显示答题次数 / 答对次数，支持整本重练或单题查看

## 三、记录存在哪

全部在**你自己浏览器的 localStorage** 里，键名 `ham_exam_data_v1`。不上传、不联网、没有服务端。

包含：每题答题次数与正确次数、考试历史、错题标记、收藏、考试草稿、界面偏好。

⚠️ **换浏览器、换设备、清理浏览器数据都会丢**。请用「统计 → 数据管理 → 导出备份（JSON）」定期存一份，换设备时用「导入备份」恢复。

## 六、题库来源与已知瑕疵

题库 PDF 来自 CRAC 官方发布的《业余无线电台操作技术能力验证题库（2025 年版）》（2025-10-01 起启用，2026 年全年沿用）。

解析过程中发现并处理了官方 PDF 的几处问题：

1. **249 道题的题号是占位符 `LX`**（源 PDF 里 `[J]` 标记未填写），另有少量题号重复。系统显示时会自动回退到题库内部唯一编号（如 `MC1-0123`），解析页里也会注明原题号。
2. **1 道题的选项标记在源 PDF 中少了一个左方括号**（`[A]57.7 伏` 印成了 `A]57.7 伏`），解析器已兼容。
3. 跨行的选项和题干在源 PDF 中是硬换行，已按「中文直连、英文补空格」的规则还原。

另外提一句：**北京无线电协会公告写的是「A 类 683 道题（其中 134 道为多选题）」，但按官方题库答案逐题统计，多选题实际是 136 道**。本系统以**官方题库答案**为准（多选题的判定依据是标准答案的字符个数），所以多选计数是 136。

## 七、自己改题库

`data/bank.json` 是结构化题库，字段说明：

```json
{
  "id": "MC1-0003",              // 题目唯一编号
  "no": "LK0007",                // 官方题号（部分为 LX）
  "uid": "LK0007",               // 显示用编号（唯一）
  "cls": ["A", "B", "C"],        // 属于哪几个类别
  "p": "1.1.1",                  // 知识点编码
  "t": "s",                      // s=单选  m=多选
  "q": "我国依法负责对业余无线电台实施监督管理的机构是：",
  "o": ["选项A", "选项B", "选项C", "选项D"],
  "a": "A",                      // 标准答案
  "img": "images/LK0497.jpg"     // 附图（可为空）
}
```

改完 `bank.json` 后重新生成 `bank.js`（这样双击打开也能用）：

```bash
cd data
python3 - <<'EOF'
import json
d = json.load(open('bank.json'))
with open('bank.js', 'w', encoding='utf-8') as f:
    f.write('window.BANK = ')
    json.dump(d, f, ensure_ascii=False, separators=(',', ':'))
    f.write(';\n')
EOF
```
