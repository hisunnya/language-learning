## 1. 这是什么

「词境 Lexica」是一个面向学生和老师的学习网站，由一个总主页和六个模块组成：

| 模块 | 目录 | 形态 |
|---|---|---|
| 总主页（词境 Lexica） | `hub/` | 纯静态：六个模块的入口、隐私说明、全站页脚（备案号） |
| 词境 Lexica（英语词汇游戏） | `word-puzzle/` | **唯一有后端的模块**：Python 标准库 + SQLite + 原生 JS |
| 每日话题 Daily Topics | `topic-app/topic-app/` | 纯静态，数据在浏览器 localStorage |
| 无线电执照 Ham Exam | `ham-exam/` | 纯静态，数据在浏览器 localStorage |
| 化学探秘 Chem Quest | `chemistry/` | 纯静态 |
| 物理探秘 Phys Quest | `physics/` | 纯静态 |
| NVIDIA 认证模拟考试 NVIDIA Exam | `nvidia-exam/` | 纯静态，数据在浏览器 localStorage |
| 微信小程序 | `miniprogram/` | **已暂停**（2026-11-18 起新功能不用同步过去） |

工作量和复杂度几乎都在 `word-puzzle/`。

## 3. 线上架构

```
                 公网（Tailscale Funnel，https）          家里局域网（http，宿主机 80 端口转发）
                              │                                   │
                              ▼                                   ▼
   ┌──────────────────────── PVE 宿主机上的 LXC 容器 lexica ─────────────────────────┐
   │  nginx 127.0.0.1:8081   word-puzzle/deploy/family/nginx/word-puzzle-family.conf │
   │    /                 → hub/（主页）               /privacy.html                  │
   │    /topics/ /ham/ /chemistry/ /physics/ /nvidia-exam/  → 静态目录             │
   │    /word-puzzle/     → web/（要登录）     /word-puzzle/api/… → 后端               │
   │    /words/           → web-public/（免登录公开版）  /words/api/… → 后端 /pub/api/… │
   │                                                                                 │
   │  后端 word-puzzle-family（systemd）127.0.0.1:8766  word-puzzle/server/app.py      │
   │    ├─ SQLite（WAL）     /var/lib/word-puzzle-family/app.db   ← 宿主机目录挂进来     │
   │    ├─ 录音 MP3          /var/lib/word-puzzle-family/recordings/                  │
   │    ├─ 语音识别          faster-whisper（单独的 venv，tools/asr_worker.py 子进程）  │
   │    └─ 朗读              Edge TTS（en-US-AriaNeural），失败时 espeak-ng             │
   │  每天 03:00 备份         lexica-backup.timer → deploy/family/backup.py            │
   └─────────────────────────────────────────────────────────────────────────────────┘
```

要点：

- **一个后端、一个数据库**。登录版和公开版是同一份代码、同一个进程，靠 URL 前缀区分：
  `/word-puzzle/api/…` 走会话 cookie 和角色；`/pub/api/…` 只接受本机（nginx）来的请求，只开放白名单里的接口
  （`Handler.PUBLIC_ROUTES`），只看得到内置的初中、高中配对题库。
- **容器是无状态的**：数据库、录音、备份都在宿主机目录里挂进来。重装容器里的代码不会丢数据。
- **计划中的迁移**：ICP 备案批下来以后，生产环境搬到北京的一台云服务器（`word-puzzle/deploy/cloud/`，
  运行手册是那里的 `部署说明.md`），家里这台变成测试环境。还没迁。

## 5. 后端模块（word-puzzle/server/）

每个文件开头都有一段中文说明，这里是索引：

| 文件 | 管什么 |
|---|---|
| `app.py` | HTTP 服务和全部路由（`Handler.do_GET` / `do_POST`）、登录检查、公开版白名单、限流、CSV 导出 |
| `db.py` | SQLite 数据层：建表、迁移（`PRAGMA user_version`，现在是 3）、常用读写；`_tx()` 是加锁的写事务 |
| `auth.py` | 账号、密码（scrypt）、会话、登录失败锁定 |
| `tenancy.py` | **谁能看到什么**：`Scope`（ALL / SUPER / TEACHER / STUDENT / GUEST / NOBODY / PUBLIC）和 `bank_where`、`student_where` 等。新的列表接口必须从这里拿条件 |
| `policy.py` | **谁能做什么**（动作级权限） |
| `bank.py` / `hierarchy.py` | 题库生成：学段 → 年级 → 册别 → 单元，切关 |
| `items.py` | 新题型（单词大比拼 spell、排排坐 order）的题目格式、Word 解析、切关 |
| `recordings.py` / `asr.py` | 排排坐的录音：收下、转 MP3、排队识别、**服务器算分**（不信页面报的分） |
| `leaderboard.py` | 积分榜（周榜 / 总榜，按玩法），`CLASSMATES` 是「学生看到的同学」的唯一定义 |
| `awards.py` | 奖状和徽章：周榜累计 10 / 15 / 30 天第一 → 铜 / 银 / 金；用到时补算 |
| `scorebook.py` | 成绩汇总（老师看的表） |
| `accesslog.py` | 访问记录（永久保留）、`Throttle` 限流器 |
| `materials.py` / `docx.py` / `pdf.py` / `wordlist.py` | 老师上传的词表解析（txt / csv / xlsx / docx / pdf） |
| `roster.py` | 学生名单解析（csv / xlsx），也提供 xlsx 读取给 materials.py 用 |
| `templates.py` / `xlsx.py` | 给老师下载的词表模板、名单模板 |
| `offline.py` | 单文件离线页（把 JS、题目、音频都内联进一个 HTML） |
| `tts.py` / `ipa.py` | 美式女声朗读、美式音标（CMUdict，**不要用 ECDICT 的音标**） |
| `modules.py` | 以后接入其他学科的登记表 |
| `admin.py` | 服务器上的管理命令行（建超管、导入名单、重置密码……） |

数据库的主要表：`users`（三种角色 admin / teacher / student，软删除 `deleted_at`）、`teacher_students`（老师和学生的关系，
第一位老师是负责老师）、`banks` + `bank_words`（配对题库）+ `bank_items`（新题型题目，JSON）、`scores`（每局成绩，
`game_type` 区分玩法）、`recordings`、`user_tags` / `bank_tags`（每位老师自己的标签，决定学生看到哪些题库）、
`share_requests`、`audit_log`、`page_views` / `login_events`（访问记录）、`app_settings`（总榜设置、奖状规则版本等）、
`awards` / `board_leaders` / `award_days`（奖状，表在 `awards.py` 里建）。

## 6. 前端（word-puzzle/web/）

- 没有构建步骤，ES5，`<script src>` 直接加载。**服务器上没有 Node.js**，JS 语法用 `tools/check_js.py` 检查。
- 页面：`index.html`（选玩法、选题库）、`play.html`（中英配对）、`spell.html`、`order.html`、`practice.html`、
  `stats.html`（成绩 + 荣誉）、`leaderboard.html`、`me.html`、`bank.html`（题库工作台）、`admin.html`（账号）、
  `tenants.html`（超管：老师、回收站、审计、总榜设置）、`visits.html`（访问记录）、`login.html`、`change-password.html`。
- 计算和界面分开：`game-core.js`（配对的计分、计时）、`item-core.js`（新题型的规则、关名）是纯函数，有 node 测试；
  `game-ui.js`、`spell-ui.js`、`order-ui.js` 是界面，网站和离线页共用。
- 双语：页面里的静态文字用 `data-module-zh` / `data-module-en`；脚本里的文字用 `WPI18N.t('key')`，
  词条都在 `js/i18n-lexica.js`，中英两份必须同样的键（`tests/test_i18n.py` 会查，也会查没用到的键）。
- **改了 `web/js`、`web/css` 或 `hub/shared` 下的任何文件，必须运行 `python3 word-puzzle/tools/bump_assets.py`**：
  页面引用的 `?v=` 是文件内容的哈希，不更新的话学生手机（尤其微信）会一直用旧文件。

## 7. 本机运行和测试

只需要 Python 3（标准库）。有 node 时会多跑几组前端行为测试，没有就跳过。

```bash
# 本机跑词境（不带登录的开发模式）
cd word-puzzle && ./run.sh                       # http://127.0.0.1:8000
# 带登录：
cd word-puzzle && WP_AUTH=1 WP_DB=var/dev.db python3 -m server.app --port 8000
WP_DB=var/dev.db python3 -m server.admin create-admin T001 --name 测试老师

# 全部测试（提交前必须全绿；用 && 串起来，任何一组失败就停）
cd word-puzzle  && python3 -m unittest discover -s tests && python3 tools/check_js.py && cd .. \
&& cd hub        && python3 -m unittest discover -s tests && cd .. \
&& cd chemistry  && python3 -m unittest discover -s tests && cd .. \
&& cd physics    && python3 -m unittest discover -s tests && cd .. \
&& cd miniprogram && python3 -m unittest discover -s tests && cd ..
```

测试里会看到 `disk full`、`Connection reset` 之类的字样：那是测试故意模拟的故障，最后一行是 `OK` 就是通过。

命令行工具（`word-puzzle/tools/`）：

| 工具 | 用途 |
|---|---|
| `bump_assets.py` | 刷新所有页面里 JS / CSS 的 `?v=` |
| `check_js.py` | 不用 node 的 JS 语法检查 |
| `import_items.py` | 把老师的 Word 文件导入成单词大比拼 / 排排坐题库（老师自己上传的页面还没做） |
| `build_public_web.py` | 安装时从 `web/` 生成公开版 `web-public/` |
| `asr_worker.py` | 语音识别子进程（后端调用，不直接用） |
| `build_seed_data.py` / `build_ipa_table.py` | 重新生成内置词库 / 美式音标表 |

## 8. 部署

### 8.1 每次提交都要做的

1. 全部测试通过（第 7 节）。
2. 改过前端文件就跑 `bump_assets.py`。
3. 把根目录的 `deploy-all-<旧时间戳>.sh` 用 `git mv` 改成新时间戳（`YYYYMMDD_HHMMSS`），和改动一起提交；
   新增模块时要同步它的文件检查、冒烟检查和打印的网址。
4. 提交信息用英文（AGENTS.md §1），作者邮箱用仓库主人的个人地址（`git config user.email`）。
5. `git rebase origin/main` 后再推。

### 8.2 上线（在 PVE 宿主机上，root）

```bash
cd /root/language-learning
bash pre-deploy.sh            # 先备份：数据库 + 已安装的代码，打印回滚命令（必须在 git pull 之前）
git pull
bash deploy-all-<时间戳>.sh    # 推进容器、在容器里重装、检查页面和接口
```

部署完用浏览器 Ctrl+Shift+R 强刷看一遍。只在本机或开发虚拟机上验证过的改动，**不能说成「生产已验证」**。

### 8.3 出问题时

- `pre-deploy.sh` 打印的回滚命令可以直接用（代码回到部署前的版本，数据库有部署前的副本）。
- 服务状态：在容器里 `systemctl status word-puzzle-family`，日志 `journalctl -u word-puzzle-family -n 200`。
- 数据库只能用服务账号打开，不要用 root 直接打开正在用的数据库（root 建出来的 `-shm` 文件会让服务打不开库）。

## 10. 还没做完的事 / 已知问题

按大致的优先级：

1. **备案号**：`hub/shared/site-footer.js` 开头的 ICP 备案号还是占位 `00000`，批下来以后改这一处；公安备案号同一个文件里可选。
2. **迁到云服务器**：备案批下来以后按 `word-puzzle/deploy/cloud/部署说明.md` 迁。注意：
   `migrate-data.sh` / `sync-from-home.sh` **只迁数据库，不迁录音目录**（`recordings/`），迁的时候要另外 rsync 过去，
   否则学生的历史录音在云上放不出来（成绩不受影响）。
3. **老师上传新题型**：单词大比拼、排排坐的题目现在只能由管理员用 `tools/import_items.py` 导入 Word 文件，
   题库工作台里还没有上传入口。
4. **站点后台 `/backends/`**：设想中的整站后台（用超管账号登录，不在主页上链接）还没有做。
5. **微信小程序暂停**：`miniprogram/` 只有中英配对（计分已和网站一致），没有单词大比拼、排排坐、积分榜、奖状；
   恢复时以网站版为准补齐（`word-puzzle/tests/js/core_parity.test.js` 守着两边配对规则一致）。
6. **词表上传时被跳过的行**：缺中文或缺英文的行会被静默跳过，老师看不到是哪几行，可以在上传结果里列出来。
7. **成绩汇总的性能**：`scorebook.py` 每次都全表汇总，学生和成绩多到几万条以上时可能需要加缓存或物化。
8. **语音识别只有一个队列**：同一时间只识别一条录音（CPU 机器上一条约几秒）；人多时会排队，结果晚一点到，
   分数会在识别完成后自动补上（`recordings.rescore`）。

## 11. 容易踩的坑

- **数据库迁移**：只能往前加（`db.py` 里 `user_version` 递增），并且「看版本 → 改数据 → 改版本」要在同一个事务里，
  参考 v3 的写法。不要改已经发布的迁移。
- **积分规则**：配对的分值在 `game-core.js`，新题型在 `item-core.js`，排排坐的最终分由服务器 `recordings.order_score` 算。
  改规则时三处和对应测试一起改，并想清楚历史成绩要不要按比例换算。
- **奖状规则**：改了 `awards.py` 的规则就要换 `RULES` 字符串，旧的榜首记录会作废重算，已发的奖状不动、不会重复发。
- **nginx 的 `add_header` 不继承**：一个 location 里只要写了 `add_header`，外层的安全头就没了；
  每个这样的 location 都要重复安全头（`tests/test_family_deploy.py` 会查）。
- **公开版**：任何新接口默认不对公开版开放；要开放就加进 `Handler.PUBLIC_ROUTES`，并确认 `tenancy.PUBLIC` 下的数据范围。
- **录音只能在 https 下**：局域网的 http 地址不能录音，这是浏览器的限制，不是 bug。
- **huggingface.co 在家里的网络连不上**：安装脚本会自动改用 hf-mirror.com 下载识别模型；不要给服务器设代理。
- **目录名不能改**：产品叫「词境 Lexica」，目录还是 `word-puzzle/`（改了会断掉 systemd、nginx 和已部署的路径）。
