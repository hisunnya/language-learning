# 每日话题 · 部署说明

## 一、文件结构

```
topic-app/                  ← 整个目录放到服务器
├── index.html              主页面
├── app.js                  前端逻辑（ES Module）
├── topics.js               话题数据（从 Excel 自动生成）
├── styles.css              样式
├── favicon.svg             网站图标
└── 初中生每日话题.xlsx      原始话题库（可选保留）
```

> 任何静态文件服务器都能跑（因为没有后端依赖，数据和状态都在浏览器 localStorage）。

---

## 二、Ubuntu + Nginx 部署步骤

### 1. 复制文件到服务器

```bash
# 在你的 Ubuntu 服务器上
sudo mkdir -p /var/www/topic-app
# 把 topic-app/ 里的所有文件 scp 上去
# （包括隐藏文件，如果有的话）
sudo chown -R www-data:www-data /var/www/topic-app
```

### 2. Nginx 配置

新建 `/etc/nginx/sites-available/topic-app`：

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name _;            # 内网不需要域名，留 _ 即可

    root /var/www/topic-app;
    index index.html;

    # 字符集
    charset utf-8;

    # 默认 gzip 压缩
    gzip on;
    gzip_types text/css application/javascript text/javascript;
    gzip_min_length 1024;

    # 静态资源缓存（数据每周更新一次可以加长）
    location ~* \.(js|css|svg)$ {
        expires 1d;
        add_header Cache-Control "public, max-age=86400";
    }

    # 主路由
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 禁止访问 .html 之外的其他类型（安全）
    location ~ /\.(?!well-known) {
        deny all;
    }
}
```

启用站点：

```bash
sudo ln -s /etc/nginx/sites-available/topic-app /etc/nginx/sites-enabled/
sudo nginx -t                  # 检查语法
sudo systemctl reload nginx    # 重载配置
```

### 3. 防火墙（如果启用了 ufw）

```bash
sudo ufw allow 80/tcp
```

### 4. 家庭内网访问

看 Ubuntu 服务器的 IP（比如 `192.168.1.100`），家里任何设备浏览器打开：
```
http://192.168.1.100
```

## 三、更换数据（话题库）

如果以后想增删话题：

1. 编辑 Excel 表格 `初中生每日话题.xlsx`
2. 重新运行 `extract_data.py` 生成 `topics.js`：

```bash
# 在本地（需要 Python + openpyxl）
pip install openpyxl
python3 extract_data.py
```

3. 把新 `topics.js` 上传到 `/var/www/topic-app/`

> 不需要重启 Nginx，刷新浏览器即可看到新数据。
> 旧的 localStorage 数据兼容新数据。

## 四、积分规则说明

| 操作 | 积分变化 |
|---|---|
| 初始赠送 | **+30 积分** |
| 完成一次讨论（未看方向） | **+10 积分** |
| 完成一次讨论（看过方向） | **+8 积分**（奖励独立完成） |
| 查看参考方向 | **-2 积分** |

积分的具体用途由你自行决定 —— 可以是游戏时长、零花钱额度、家庭活动券，等等。网页只负责记录积分数字，不和任何具体兑换方式绑定。

修改积分规则：编辑 `topic-app/app.js` 顶部的 `POINTS` 对象。

## 五、localStorage 数据

所有用户数据都存在浏览器本地（localStorage），包括：
- `tp_points` — 当前积分
- `tp_used_ids` — 已抽过的话题 ID（避免重复）
- `tp_restored_ids` — 被放回话题库的话题（优先抽取）
- `tp_history` — 历史讨论记录

清空数据：在浏览器 console 执行 `localStorage.clear()` 然后刷新。

## 六、可选优化（按需）

### 6.1 用 HTTPS（如果家里有公网 IP 或想用域名）

```bash
# 用 Let's Encrypt + DNS challenge
sudo apt install certbot
sudo certbot certonly --nginx -d yourdomain.com
# certbot 会自动改写 Nginx 配置启用 HTTPS
```

### 6.2 加 LAN-only 访问限制（更安全）

只允许家里子网访问，编辑 `/etc/nginx/sites-available/topic-app`：

```nginx
server {
    ...
    location / {
        allow 192.168.1.0/24;    # 改成你的子网
        deny all;
        try_files $uri $uri/ /index.html;
    }
}
```

### 6.3 局域网自动发现（mDNS）

服务器装 `avahi-daemon`，家里其他设备用 `http://topic-app.local` 访问：

```bash
sudo apt install avahi-daemon
sudo systemctl enable --now avahi-daemon
```

## 七、常见问题

**Q: 浏览器提示 "Failed to fetch" 或模块加载错误？**
A: 必须用 HTTP 服务访问，不能直接 `file://` 打开 index.html（Nginx 已经解决）。

**Q: 换了浏览器数据没了？**
A: 是的，localStorage 是按浏览器和设备分别存的。如需跨设备共享，需要加后端 API。

**Q: 想给孩子账号区分？**
A: 当前没有身份认证，多人共用一份数据。如果要区分，需要后端（Flask/FastAPI + 数据库）。

**Q: 全部话题都讨论过了怎么办？**
A: 当前会提示"所有话题都讨论过啦"。可以去历史页面把一些放回话题库；或者编辑 Excel 加新话题。

## 九、主题切换

网页内置 3 套主题：

- **暖棕**（默认）：焦糖棕 + 米白
- **森绿**：橄榄绿 + 米绿
- **雾蓝**：钢蓝 + 灰白

切换方法：点击右上角调色板图标按钮，选择主题。主题偏好会保存在浏览器的 localStorage，下次打开自动应用。

修改/新增主题：编辑 `topic-app/styles.css` 顶部的 `[data-theme="..."]` 变量块。
